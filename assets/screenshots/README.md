# Screenshots

Recommended filenames:

```text
linux-dashboard.png
linux-telegram.png
linux-files.png
windows-dashboard.png
windows-telegram.png
windows-setup.png
windows-services.png
```

Before committing screenshots:

- remove Telegram bot tokens;
- remove dashboard login tokens;
- remove private URLs if sensitive;
- remove passwords/API keys;
- review terminal output;
- review file paths and usernames;
- keep images reasonably compressed.
